# Search Algorithms

Small Python examples of search and optimization algorithms:

- `A_star.py` — A* graph search
- `ao.py` — AO* search on an AND-OR graph
- `hill.py` — hill climbing for a one-dimensional function
- `Untitled-1.py` — minimax with alpha-beta pruning

Run an example with Python 3, for example:

```bash
python A_star.py
```
